# recruta.de versão blindada

Esta versão evita problemas de caminho no GitHub Pages.

Arquivos:

index.html
es.html
de.html
privacidade.html
cookies.html
impressum.html

O CSS, JavaScript, logo e imagem principal estão embutidos nos arquivos HTML.

Para publicar:

1. Envie todos estes arquivos para a raiz do repositório
2. Vá em Settings
3. Pages
4. Selecione branch main
5. Folder root
6. Save

Observação:

Nesta versão não existem pastas `es` e `de`.
O seletor de idiomas usa `es.html` e `de.html`.
